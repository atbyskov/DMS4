\section*{Overview of the Electronic Appendix}
\label{app:electronic}

This appendix describes the contents of the electronic appendix, which contains the full Python-based optimization framework coupled with ANSYS MAPDL for structural optimization of the mast geometry.

\subsection*{Entry Points}

\begin{description}[style=nextline, leftmargin=2.5cm]

    \item[\texttt{Main.py}]
    Primary optimization driver using the PySLSQP optimizer.
    Defines design variables, bounds, loads, and material properties, launches ANSYS MAPDL, and runs the iterative optimization loop.

    \item[\texttt{Main\_SLP.py}]
    Alternative optimization driver using the custom Sequential Linear Programming (SLP) solver.
    Same workflow as \texttt{Main.py} but routes through the SLP-specific modules in the \texttt{SLP/} folder.

    \item[\texttt{Main\_Test.py}]
    Standalone analysis script that runs a single finite element evaluation without optimization.
    Used to inspect structural response (utilization ratios, eigenvalues, masses) for a given set of design variables.

\end{description}

\subsection*{Core Modules}

\begin{description}[style=nextline, leftmargin=2.5cm]

    \item[\texttt{optimization.py}]
    Orchestrates the PySLSQP optimization loop: filters active variables, evaluates the FE model, collects constraints, applies aggregation and ACS, and forwards everything to the solver.

    \item[\texttt{MyAPDLCall.py}]
    Interface between the optimization framework and ANSYS MAPDL.
    Accepts design variables, builds the APDL input commands, executes the finite element analysis, and returns the total mass and per-segment masses.

    \item[\texttt{APDL\_Input.py}]
    Generates the complete ANSYS APDL command script from a parametric geometry definition.
    Handles meshing, cross-section assignment, boundary conditions, loading, eigenvalue buckling analysis, and nonlinear static analysis.

    \item[\texttt{Post\_Process.py}]
    Post-processes MAPDL results and evaluates structural utilization checks according to Eurocode~3.
    Computes utilization ratios for local buckling, normal force, shear, torsion, buckling resistance, member interaction, and brace checks.

    \item[\texttt{SW\_Import.py}]
    Parses IGES geometry files exported from SolidWorks.
    Extracts line-entity coordinates that define the beam topology of the mast structure.

    \item[\texttt{aggregate.py}]
    Provides constraint aggregation methods (P-norm, P-norm-mean) that reduce multiple constraint values into a single smooth scalar for gradient-based optimization.

    \item[\texttt{acs.py}]
    Implements Adaptive Constraint Scaling (ACS) to improve convergence by dynamically scaling the aggregated constraint so that it tracks the true maximum violation.

    \item[\texttt{opt\_logger.py}]
    Logging module that records per-iteration progress and per-evaluation objective history.
    Produces a detailed text log and a CSV file of every function evaluation, stored in \texttt{Optimization\_Logs/}.

    \item[\texttt{search\_space.py}]
    Design-space sampling utility for generating initial starting points.
    Supports grid, random, Latin Hypercube, and Sobol sampling methods to explore the variable space before optimization.

\end{description}

\subsection*{SLP Solver Modules (\texttt{SLP/} folder)}

\begin{description}[style=nextline, leftmargin=2.5cm]

    \item[\texttt{SLP/optimization\_SLP.py}]
    SLP-specific optimization orchestrator, analogous to \texttt{optimization.py}.
    Manages the model evaluation loop, constraint assembly, and logging when using the custom SLP solver.

    \item[\texttt{SLP/SLP.py}]
    Core Sequential Linear Programming solver implementing a merit-function approach with slack variables, an LP subproblem, a Fletcher--Leyffer--Toint filter for globalization, and adaptive move limits.

\end{description}

\subsection*{Data and Output Folders}

\begin{description}[style=nextline, leftmargin=2.5cm]

    \item[\texttt{IGS/}]
    Contains the IGES geometry file (\texttt{LWC\_L1\_LINES.IGS}) defining the mast wireframe exported from SolidWorks.

    \item[\texttt{Ansout/}]
    Working directory used by ANSYS MAPDL during finite element analysis runs. Contains temporary solver files generated at runtime.

    \item[\texttt{Optimization\_Logs/}]
    Output directory for optimization log files. Stores per-run text logs and CSV evaluation histories produced by \texttt{opt\_logger.py}.

\end{description}
